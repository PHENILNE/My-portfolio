 React Portfolio Website

Features:
- Fast development & build with Vite
- Responsive design (mobile-friendly)
- Clean and modern UI
- Component-based architecture with React
- Easy to customize and extend

Tech Stack :
- React
- Vite
- JavaScript 
- CSS
